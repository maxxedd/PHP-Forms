Feedback Hub - ICT123 Lab 5

A modern, responsive feedback submission web application featuring glassmorphism UI design, client-side JavaScript validation, and server-side PHP processing.

📁 File Structure

process.php / index.php: The main page containing the HTML form and server-side PHP validation logic. Displays submitted feedback in a thank-you card at the bottom of the page upon successful submission.

style.css: Defines modern glassmorphism styling, layout, custom variables, animations, and typography.

app.js: Contains client-side form validation logic to prevent empty or invalid submissions before sending data to the server.

✨ Features

Double-Layer Validation: Validates user inputs on both the client side (JavaScript) and server side (PHP).

Persistent Layout: Form remains visible with cleared inputs after submission, allowing multiple entries.

Dynamic Response Card: Successfully processed submissions display a styled summary card directly below the form.

Responsive & Modern UI: Built with a sleek glassmorphism aesthetic using CSS variables and smooth animations.
